# AI Mock Interview System

A full-stack application that leverages AI to conduct customized mock interviews. Users can upload their resume, get their skills analyzed, and go through a personalized technical interview generated by Google's Gemini AI.

## 🚀 Features
- **Smart Resume Analysis**: Upload a PDF resume. The system automatically extracts your skills and formulates tailored interview questions.
- **AI-Powered Mock Interviews**: Real-time evaluation of your answers using Google Gemini. Get immediate feedback and scoring!
- **Secure Authentication**: JWT-based authentication system for user signups and logins.
- **Dashboard Analytics**: Track your previous mock interviews, average scores, and performance history over time.
- **Modern UI**: A premium, responsive interface built with React and Tailwind CSS.

## 🛠️ Tech Stack
- **Frontend**: React (via Vite), Tailwind CSS, React Router
- **Backend**: Node.js, Express.js
- **Database**: PostgreSQL (hosted on Supabase)
- **AI Integration**: Google Gemini API

## 🏁 Getting Started (Step-by-Step)

### Prerequisites
- [Node.js](https://nodejs.org/) (v16+ recommended)
- A [Supabase](https://supabase.com/) account / PostgreSQL database
- A [Google Gemini API Key](https://aistudio.google.com/app/apikey)

### 1. Clone the Repository
```bash
git clone https://github.com/codeaman28/Ai-Mock-interview.git
cd Ai-Mock-interview
```

### 2. Set up the Backend (`/server`)
1. Navigate to the backend folder:
   ```bash
   cd server
   ```
2. Install the necessary dependencies:
   ```bash
   npm install
   ```
3. Create a `.env` file in the `server` directory and add the following keys (refer to `.env.example`):
   ```env
   DB_USER=your_db_user
   DB_HOST=your_db_host
   DB_NAME=postgres
   DB_PASSWORD=your_db_password
   DB_PORT=6543
   
   SUPABASE_URL=your_supabase_url
   SUPABASE_PUBLISHABLE_KEY=your_supabase_key
   
   JWT_SECRET=your_super_secret_jwt_key
   JWT_EXPIRES_IN=7d
   
   PORT=5000
   NODE_ENV=development
   ALLOWED_ORIGINS=http://localhost:5173
   
   GEMINI_API_KEY=your_gemini_api_key
   ```
4. Run the database setup (if applicable) or run migrations against your Supabase instance to create the required tables.
5. Start the backend development server:
   ```bash
   npm run dev
   ```
   _The backend should now be running on http://localhost:5000_

### 3. Set up the Frontend (`/client`)
1. Open a new terminal window and navigate to the frontend folder:
   ```bash
   cd client
   ```
2. Install the frontend dependencies:
   ```bash
   npm install
   ```
3. Create a `.env` file inside the `client` directory and configure your backend endpoint:
   ```env
   VITE_API_URL=http://localhost:5000/api
   VITE_SUPABASE_URL=your_supabase_url
   VITE_SUPABASE_PUBLISHABLE_KEY=your_supabase_key
   ```
4. Start the frontend development server:
   ```bash
   npm run dev
   ```
   _The frontend will start on http://localhost:5173_

### 4. Start Practicing!
Open your browser and navigate to `http://localhost:5173`. Create an account, upload your resume, and start your first AI mock interview!
